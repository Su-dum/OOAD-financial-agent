# 情景分析（D4：Scenario Analysis）

> 评分原文：*Allow users to modify selected assumptions or market conditions and analyze their
> potential impact on financial assets or portfolios.*
>
> 这是高级项里最后一个没做的部分。本文记录：支持哪些假设、怎么算、接口与界面、实测与限制。

## 一、能改哪些假设

| 假设 | 参数 | 范围 | 影响 |
|---|---|---|---|
| **市场冲击** | `market_shock` | [−0.5, 0.5] | 基准一次性涨跌，按 β 传导到每只标的 |
| **波动率倍数** | `vol_multiplier` | [0.2, 5] | 协方差矩阵整体乘 k²，VaR/ES 同比放大 |
| **相关性压力** | `correlation_stress` | [0, 1] | 资产间相关性向 1 靠拢（危机时一起跌） |
| **直接回撤** | `drawdown` | [−0.6, 0] | 组合累积承受一次回撤，与冲击**复利叠加**成情景合计影响 |
| **持有期** | `horizon_days` | [1, 250] | 持有期 VaR 与历史重放窗口长度 |

组合 = 一组标的 + 权重（不传权重则等权；负数按 0 处理，权重自动归一化）。

## 二、怎么算（全部是确定性计算，不经过 LLM）

设对齐后的日收益率序列 `r_i,t`、权重 `w_i`、基准日收益率 `r_m,t`：

| 指标 | 公式 |
|---|---|
| 组合日收益 | `r_p,t = Σ w_i · r_i,t`（每日再平衡口径） |
| 组合年化波动 | `σ_p · √252`，其中 `σ_p = √(wᵀΣw)` |
| 组合 β | `cov(r_p, r_m) / var(r_m)` |
| 市场冲击传导 | `冲击_p = Σ w_i · β_i · s_m`（逐标的 `β_i · s_m` 为单标的冲击） |
| 波动率倍数 | `Σ' = k² · Σ` ⇒ `σ_p' = k · σ_p` |
| 相关性压力 | `R' = (1−λ)R + λJ`，`Σ' = D R' D`（`J` 全 1 矩阵） |
| 参数法 VaR | `VaR_α = z_α · σ − μ`（正数=亏损幅度） |
| 参数法 ES/CVaR | `ES_α = σ · φ(z_α)/(1−α) − μ` |
| 持有期 VaR | 波动按 `√h`、均值按 `h` 缩放 |
| **情景合计影响** | `(1+冲击_p)(1+drawdown) − 1`（**复利叠加**，不是相加） |
| **回本需涨幅** | `\|损失\| / (1 − \|损失\|)`：亏 20% 需涨 25%，亏 50% 需涨 100% |
| 历史最差窗口 | 滚动 `h` 日买入持有：`R = Σ w_i·Π(1+r_i) − 1`，取最小 |

> ⚠️ **两类指标不要混着读**：
> 「市场冲击传导 / 情景合计影响 / 回本需涨幅」是**特定情形的点估计**（这种情形亏多少）；
> 「年化波动 / VaR / ES」是**分布法**，由波动率与相关性假设推出（通常能亏多少）。
> 把 `drawdown` 揉进 σ 是错的——它是一次累积事件，不是波动率。代码里有测试钉住这一点
> （`test_drawdown_does_not_move_distribution_metrics`）。

几个实现细节：

1. **为什么相关性压力用凸组合**：`R` 与 `J` 都是半正定矩阵，凸组合仍半正定，
   所以 `σ_p'` 一定可开方、数值稳定。`λ=0` 保持原样，`λ=1` 表示完全同涨同跌。
2. **为什么市场冲击走 β**：β 来自历史回归，把「同涨同跌」的暴露量化出来；
   基准不可用时退回 β=1 并在 `notes` 里**明确写出**，而不是假装算过。
3. **为什么同时给历史重放**：参数法假设正态、会低估尾部；历史最差窗口是真实发生过的路径，
   两者并列，答辩时可以说清「模型假设 vs 历史证据」。

代码：`core/scenario.py`（纯函数，27 个测试覆盖）+ `application/scenario_service.py`（编排）。

## 三、接口

```bash
curl -X POST http://127.0.0.1:8000/api/scenario \
  -H "Content-Type: application/json" \
  -d '{
    "codes": ["600519", "000001", "300750"],
    "start": "2025-11-25", "end": "2026-11-25",
    "market_shock": -0.10,
    "vol_multiplier": 1.5,
    "correlation_stress": 0.6,
    "drawdown": -0.15,
    "horizon_days": 20,
    "source": "sina"
  }'
```

## 四、前端

`ScenarioPanel.tsx`（跨资产面板下方）：

- 滑杆：市场冲击 / 波动率倍数 / 相关性压力 / 持有期 / 直接回撤（可勾选）
- 卡片：市场冲击传导、年化波动（基线→压力）、1 日 VaR95/99、持有期 VaR95、
  **情景合计影响**（冲击 ⊕ 回撤，标注「复利，非相加」）、**回本需涨幅**
- 卡片上方有一行口径说明，明确区分「点估计」与「分布法」
- 表格：逐标的 权重 / β / 单标的冲击 / 对组合贡献 / 压力后波动
- 历史最差窗口：日期区间、组合收益、各标的收益
- 注意：面板默认用**新浪快源**（`source="sina"`）——情景是交互操作，不能被 baostock 的
  半挂起拖住；新浪 qfq 口径同样可信（`docs/datasource-eval.md` §7.5）

实测（等权三只票，冲击 −10% / 波动 ×1.5 / 相关性 0.6）：

| drawdown | 冲击传导 | 合计影响 | 回本需涨幅 |
|---|---|---|---|
| 不勾选 | −3.30% | −3.30% | +3.41% |
| −15% | −3.30% | **−17.81%** | **+21.66%** |
| −30% | −3.30% | −32.31% | +47.73% |
| −60% | −3.30% | −61.32% | +158.53% |

（合计影响 = (1−3.30%)×(1−15%)−1 = −17.81%，而非相加的 −18.30%）

## 五、实测与校验

| 项目 | 结果 |
|---|---|
| 单元测试 | `tests/test_scenario.py` **42 个**：协方差/组合波动解析解、压力变换（λ=1 ⇒ σ_p=Σwσ）、VaR/ES 已知值、权重归一化、最差窗口、β 传导、缺基准回退、参数校验 |
| 组合 β 一致性 | 逐标的 β 加权 = 组合 β（测试断言） |
| 冲击可加性 | Σ 贡献 = 组合冲击（−3.30% vs −3.29%，舍入差） |
| 实网请求 | 3 只标的 × 243 个交易日，约 10 秒（新浪源） |
| 点估计一致性 | `total_impact` = `(1+冲击)(1+回撤)−1`；`recovery_gain` = `\|t\|/(1−\|t\|)`（测试断言） |

## 六、已知限制

1. **参数法假设正态**：厚尾、跳跃、涨跌停会被低估；所以并列历史最差窗口作为交叉验证。
2. **市场冲击是线性的**：按 β 传导，不建模「波动率与冲击同时放大」的反馈（可以叠加
   `vol_multiplier` 手动近似）。
3. **相关性压力不对指数做约束**：压力后相关性可能高于历史上任意时期，属于「假设推演」，
   不代表预测。
4. **组合口径是每日再平衡**：不做再平衡（买入持有）的组合，长期路径会略有差异；
   历史重放用的是买入持有口径。
5. **不含交易成本、税费、流动性**；也不考虑停牌/涨跌停无法成交。
6. **「冲击 ⊕ 回撤」有先后假设**：按「先一次性冲击、再累积回撤」复利叠加，两者不重叠；
   若用户的回撤本身已包含冲击，应取消勾选（notes 里会提醒）。
7. **权重只能在 API 设**：界面没有权重输入框，一律等权（`POST /api/scenario` 的
   `weights` 字段可用，但前端未暴露）。
8. **结果不构成投资建议**（响应里也会带这条 note）。
